# ZPS Studio 0.1.12

Dark mode, and less clutter.

- **⚙ 设置** in the bottom-left corner opens settings. Under 外观, choose 浅色, 深色 or 跟随系统. 跟随系统 matches Windows. Your choice is remembered.
- The File / Edit / View / Window / Help menu bar at the top of the window is removed.
- Font choices in BUFF增强 are labeled 样式 1, 样式 2 and so on. Hover one to see its font number. The 其他 button is removed.

Editing, export, updates and plugin data formats are unchanged.
