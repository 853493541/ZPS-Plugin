# ZPS Studio 0.1.15

Updates are quieter.

- New versions download silently in the background. Nothing appears while one is being found or downloaded.
- When the download is complete, a single **重启更新** button appears in the bottom-left corner. Click it to restart into the new version.
- If you have unexported changes, the corner shows one short line, 请先导出或撤销修改, and the same button works again once they are resolved.
- If a restart attempt fails, the button changes to **重试**.

Editing, export and plugin data formats are unchanged.
