# ZPS Studio 0.1.16

A cleaner top of the window.

- The large file name, 文件信息 and the 撤销 / 新建数据集 / 导入文件 / 导出当前数据集 buttons are gone. The file tabs now sit at the top.
- A **＋** at the end of the tabs offers 新建数据集 and 导入文件.
- Right-click a tab for 复制为新版本, 重命名版本, 导出, 文件信息 and 关闭. Renaming happens right in the tab.
- **Ctrl+Z** undoes and **Ctrl+S** exports.
- Built-in samples no longer show a 内置样本 label or a read-only bar. They stay locked: edit controls are greyed out, and right-click → 复制为新版本 gives you an editable copy.
- A tab shows its folder only when another open tab has the same name and version.

Editing, updates and plugin data formats are unchanged.
