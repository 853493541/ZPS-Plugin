# ZPS Studio 0.1.9

BUFF增强 types now show what their border looks like.

- Each type in the type list and the selected type's heading show a small preview of its border.
- **类型样式与名称** and **新建类型** show a large preview under 边框编号, plus a row of all available borders. Click one to choose it. Choosing a border also turns on 启用自定义边框.
- Border numbers without a preview image, such as 61, show their number. A type with the custom border turned off shows a dashed outline.

Border images cover numbers 1, 7, 9, 10, 11, 12, 13, 14 and 45. Font previews are not included yet. Editing, export, updates and plugin data formats are unchanged.
