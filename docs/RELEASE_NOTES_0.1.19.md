# ZPS Studio 0.1.19

- Messages now appear at the top of the window, above any open window.
- Right-click a buff to delete it. Ctrl+Z brings it back.
- Click a type's name to rename it. The pen button and the extra box are gone.
- The tab menu now says 复制 and 重命名.
- A copy is named after the original, for example BuffData.jx3dat（副本）.
- Buttons now read 添加 Buff and 新建类型.
- 启用 is a checkbox next to the buff count. Turned-off types show a 停用 tag in the left list.
- The left list shows each type's first buff inside its border.
- 生效等级 shows each level as a checkbox. The JSON hint is gone.

Export, updates and plugin data formats are unchanged.
