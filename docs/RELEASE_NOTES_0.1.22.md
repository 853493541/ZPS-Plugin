# ZPS Studio 0.1.22

- 文字字体 now shows each font as "字体预览" in its in-game color, size, outline and weight, instead of a number.
- Fonts are listed in the same order as the plugin's font list.
- Which font number matches which style is a best guess for now (沉默 is red). Hover a font to see its number.
- Font previews keep their full colors on locked built-in samples.

Editing, export, history, updates and plugin data formats are unchanged.
