# ZPS Studio 0.1.6

The workspace drops controls that repeated information shown elsewhere.

- The sidebar import button is gone. Use **导入文件** in the toolbar or Ctrl+O.
- The small feature label above the file name is gone. The highlighted sidebar tab shows the active feature.
- The row above the record table with the entry count is gone. The table footer still shows the visible and total counts.
- Hidden leftover panels that never appeared are removed.

Editing, export, updates and plugin data formats are unchanged.
