# ZPS Studio 0.1.14

Built-in samples are locked, copying is instant, and dark mode has no green left.

- **Built-in samples are read-only.** Their tab shows 🔒 内置样本, and a bar above the workspace explains it. Every edit control is off for a sample.
- **复制** copies right away, with no window to fill in. The copy opens as 版本 2, then 版本 3 and so on, and you can edit it at once. Find 复制 in the read-only bar or in the tab's right-click menu.
- **Name a version** with the ✎ next to the version name under the file name. Enter saves and Esc cancels.
- **深色 mode** no longer shows green or teal anywhere. That includes the backdrop behind windows, shadows, the selected row marker, the install button and the sidebar text.

Export, updates and plugin data formats are unchanged.
