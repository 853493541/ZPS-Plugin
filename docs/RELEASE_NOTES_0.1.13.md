# ZPS Studio 0.1.13

Faster buff adding and a proper dark mode.

- **添加 Buff** takes a Buff ID only. Studio looks it up on JX3BOX as you type and shows its name and icon. If the buff is already in a type, it says which one and does not add it again. Use **移到此类型** to move it instead.
- The type name has a ✎ pen button for renaming, and the buff count sits right next to the name.
- Border choices stay on one line.
- Font choices read 无, 1, 2, 3 and so on.
- **深色** mode is now neutral black and grey, with no green tint.

Export, updates and plugin data formats are unchanged.
