# ZPS Studio 0.1.7

Dialogs are quicker to dismiss and no longer blur the window behind them.

- Click anywhere outside an open dialog to close it. This works for the record detail window and for every other dialog, such as file info, new dataset, add Buff and problem report.
- Closing by clicking outside behaves the same as Escape or the close button. Unapplied edits in the detail window stay as drafts.
- Pressing inside a dialog and releasing outside it, for example while selecting text, does not close it.
- The background behind a dialog is dimmed but stays sharp. Blur effects are no longer used anywhere in the app.

Editing, export, updates and plugin data formats are unchanged.
