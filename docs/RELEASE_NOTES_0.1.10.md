# ZPS Studio 0.1.10

Editing a BUFF增强 type now happens right above its buff list, where you can see the result.

- The selected type shows a settings card: 启用, 图标边框 and 文字字体. Every change applies immediately, and **撤销** undoes it.
- Click the type name to rename it. Press Enter to save or Esc to cancel.
- Pick a border from the row of previews, or choose 无 to turn the custom border off. Each buff in the list below shows the type's border around its icon, so you see what the game shows.
- Types without style settings explain why: unassigned buffs have none, and a type that buffs reference but the file never defined offers **创建样式设置**.
- The separate 类型样式与名称 window is gone.

In small windows the card is more compact and the type area scrolls. Font previews are still not available. Export, updates and plugin data formats are unchanged.
