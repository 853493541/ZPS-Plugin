# ZPS Studio 0.1.20

- New: 历史. Every export now saves a copy automatically, on this computer only.
- Right-click a tab and choose 历史 to see past exports of that file, newest first.
- Each entry shows what changed since the export before it: Buffs added, deleted and modified, and which settings changed.
- 打开 opens an old export as a new tab, so what you have open is never replaced.
- The newest 50 exports of each file are kept.

Editing, export files, updates and plugin data formats are unchanged.
