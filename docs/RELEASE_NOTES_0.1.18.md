# ZPS Studio 0.1.18

- Menus show only the actions you can take. Unavailable items are hidden instead of greyed out.
- Built-in samples cannot be closed. Their tab menu offers 复制为新版本 and 文件信息.
- The top-right lock note is gone.
- The type list and buff area now reach the window edges, and the bottom status line is removed.

Editing, export, updates and plugin data formats are unchanged.
