# ZPS Studio 0.1.21

- Drag a Buff onto another Buff in the same type to change their order. A line shows where it will land. Ctrl+Z puts it back.
- Only the order of entries in the file changes. 显示优先级 and every other setting stay as they are.
- Dragging a Buff onto a type in the left list still moves it into that type.
- Deleting the last Buff in a file no longer leaves an empty line behind.

Export, history, updates and plugin data formats are unchanged.
