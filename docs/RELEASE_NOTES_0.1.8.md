# ZPS Studio 0.1.8

Buff types now have proper settings in BUFF增强.

- **新建类型** lets you set 启用, 启用自定义边框, 边框编号, 启用自定义字体 and 字体编号 while creating the type.
- **类型样式与名称** shows the same five settings as on/off choices and numbers, instead of raw `true` and number fields hidden under 高级.
- A type that lacks some of these settings in the file shows them as 未设置. Set one and Studio writes it into that type. Settings you leave as 未设置 are not added.

Other fields, export, updates and plugin data formats are unchanged.
